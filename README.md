# 白書・判例ドリル

2027年（第59回）社会保険労務士試験の「労務管理その他の労働に関する一般常識（労一）」と「社会保険に関する一般常識（社一）」の選択式に特化した、スマホ向けの学習アプリです。

## できること
- **過去問分析**：令和2〜8年の選択式の出題元（統計・白書・判例・法令）と、基準点の救済の記録
- **判例・条文**：判旨の決まり文句や目的条文を穴埋めで練習（2027年向けの優先度S/A/B付き）
- **白書・統計**：2026年10月時点の最新の公表値。方向ドリル（上昇／低下）つき
- **選択式**：本試験形式の演習（空欄ごと4択／20語の語群）
- **追加**：白書やテキストの1文を、答えを【 】で囲むだけで穴埋めカードにする

学習記録は各自のブラウザ（localStorage）に保存されます。サーバーには送られません。

## 開き方
GitHub Pages で公開しています。スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。

## 更新のしかた
本文は `sharoushi-hanrei-hakusho.html` に書きます。編集したら次を実行して `index.html` を作り直し、コミットします。

```bash
python build.py
```

## 注意
- 判旨は受験用に要約したものです。判決の原文は裁判所のWebサイトで確認してください。
- 統計の数値は、各カードの「出典を開く」から公表元を確認できます。一部は解説記事から取っています。
